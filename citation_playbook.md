# Citation Playbook: AI Disaster Response ML Research

Evidence-based tactics from bibliometric studies (arXiv:2401.11116, Nature Index, CASRAI/ASEO).

## Tactics Applied to Every Published Paper

1. **arXiv-first**: Post to arXiv BEFORE conference deadline (first-mover advantage; +21 citations avg for CS over 5 years). Do not wait for camera-ready.
2. **Title engineering**: Short title, colon-separated ("<Claim>: <Method>"), NO question marks, NO hyphens. Front-load exact search terms researchers would type.
3. **Abstract SEO**: First sentence = contribution + number. Include field keyword vocabulary and benchmark names verbatim.
4. **Open everything**: Code + data + experiment logs in public repo linked from paper (+25% citations avg). One-click reproducibility.
5. **Benchmark presence**: Be on Papers with Code leaderboard if topic has one. Leaderboard entry = permanent citation magnet.
6. **Identity hygiene**: ORCID linked, consistent author-name form, complete DOI metadata at submission.
7. **Promotion**: Author posts on X/Bluesky/LinkedIn with arXiv link + 3-line claim (author tweeting ≈ +28-44 citations for CS).
8. **Revision loop**: After reviews/conference feedback, revise the arXiv version — revised papers out-cite unrevised ones.
9. **Related Work anchoring**: Cite high-citation papers of the field PROPERLY in Related Work (where their authors will look).
10. **No manipulation**: Never citation-cartel, never coercive citations, never padded self-citation.
